# Правила для тестов

- Один тест проверяет одно поведение; имя описывает поведение, а не метод.
- Схема given / when / then, без логики и ветвлений в самом тесте.
- Юнит-тесты не ходят в сеть, в реальный Telegram, в реальную LLM и в реальную PostgreSQL: внешнее подменяется заглушками.
- Проверяй наблюдаемое поведение, а не порядок вызовов и приватные методы.
- e2e-тесты Playwright: селекторы по `data-testid` или роли, не по тексту вёрстки и не по CSS-классам; в каждом тесте проверяй, что в консоли нет ошибок.
