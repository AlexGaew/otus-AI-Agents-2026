# Память между сессиями

- В начале сессии прочитай `docs/plan.md` и `docs/memory.md` (они подключены в `CLAUDE.md`) и продолжай с пункта «Дальше», а не с нуля.
- В конце сессии или после завершённого шага добавь сверху `docs/memory.md` запись: «Сделано», «Решение», «Дальше», «Ловушки».
- Отмечай шаг в `docs/plan.md` выполненным только после прохождения тестов.
- Не дублируй в журнале то, что видно из кода и `git log`; записывай решения, их причины и ловушки.
