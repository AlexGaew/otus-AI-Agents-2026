# Правила для кода бота (src/main)

- Любой апдейт Telegram сначала проходит проверку белого списка ID. Для постороннего: ничего не отвечать и ничего не сохранять.
- Секреты (токен бота, ключ модели, пароль БД) читаются только из переменных окружения через конфигурацию Spring. Не логировать токены и ключи.
- Сбой LLM или недоступная страница по ссылке не должны терять запись: сохранить без тегов или без краткого содержания.
- Обращения к LLM изолированы за интерфейсом, чтобы в тестах подменять их заглушкой.
- Не добавлять функциональность из раздела «Вне рамок» ТЗ.
